# Enescu School of Music — website

Static website for enescuschool.com (plain HTML, CSS and JavaScript — no build step).
Hosted on Netlify; every push to `main` deploys automatically.

- Pages: `index.html`, `instruments.html`, `about.html`, `schedule.html`, `contact.html`, `thank-you.html`, `404.html`
- Styles: `css/style.css` · Script: `js/main.js` · Images and video: `assets/`
- Booking form: Netlify Forms (`lesson-request`), notifications set in the Netlify dashboard
- `_redirects`: old `instructors.html` → `about.html`
- `DEPLOY.md`: first-time Netlify and domain setup
